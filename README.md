# 剩菜盲盒 🥡（v1 验证版）

西雅图周边中餐馆的剩菜盲盒双边市场：餐馆把打烊前卖不完的菜打包成低价盲盒上架，
客人在线预订、到店出示取餐码付款自取。另支持**一周 5 天套餐**（上班族一次订走周一到周五）。

技术栈：Node.js + Express + better-sqlite3，服务端渲染 HTML，无构建步骤。

## 快速启动

```bash
npm install
node server.js
# → http://localhost:3000
```

## 页面一览

| 路由 | 说明 |
|---|---|
| `GET /` | 首页：今日可订盲盒 + 商家入驻入口 |
| `GET /box/:id` | 盲盒详情 + 预订表单 |
| `POST /reserve` | 提交预订 → 生成 6 位取餐码（单次 1 个，一周套餐 5 个） |
| `GET /my` | 买家用手机号查预订 / 取消 |
| `GET /join` | 商家入驻说明（玩法、免费入驻、抽成占位） |
| `GET /merchant/*` | 商家注册、登录、后台（发布盲盒、看预订、输入取餐码核销） |
| `GET /admin` | 管理后台（密码门）：统计 + 分餐馆成交额（抽成对账） |

## 一周套餐说明

- 商家发布时选类型「一周 5 天套餐」，填**周一日期**、每天取餐时间段、**一周总价**、套数。
- 买家预订一次生成 5 个取餐码（周一–周五各 1 个），成功页和「我的预订」按天列出。
- 5 个码各自独立核销；取消则整周一起取消并返还 1 套库存。
- 过期规则：过周五取餐结束时间整单变「已过期」；份数（套数）为 0 变「已抢光」。

## 重置数据库

```bash
npm run reset # 删除 data/shengcai.db
node server.js # 重启后自动重建表并生成示例数据
```

示例数据标注了字样，商家后台可删除无预订记录的盲盒。

## 环境变量

| 变量 | 默认 | 说明 |
|---|---|---|
| `PORT` | 3000 | 监听端口 |

## 约束（v1）

- 不做在线支付，一律到店付款。
- 登录 session 存在内存里，重启服务后需重新登录（生产环境可换 Redis/pg store）。
